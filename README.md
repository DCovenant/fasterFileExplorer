FasterFileSearch

- The motivation of this app was the bad performance file explorer search feature. The fact that it only feels fast because there are already indexed paths of files saved in cache is delusional.
Files that might have the correspondent search sometimes dont show, exactly because they are not indexed.

- This script resolves that issue by using the fd-find library that is much much faster and accurate when searching files.

- The app was built in c++ and qt, so expect it not to be that pretty, in my oppinion not that ugly either.

- The use is simple, try it.
